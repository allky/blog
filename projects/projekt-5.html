🩺 Multi-class disease classification based on symptoms

📠 Machine Learning 📅 may 2025 🏫 School Project

✨ ABOUT PROJECT

This project was developed as part of the OZNAL (Knowledge Discovery) course during my studies at FIIT STU. I worked on the project as a pair with my classmate Lenka ♡.

The goal of the project was to develop a multi-class classification system capable of diagnosing common diseases based on patient symptoms. Our solution was implemented as an interactive Shiny application in R, leveraging machine learning techniques to distinguish between eight different medical conditions: Asthma, Dengue, Malaria, Common Cold, Cough, Body Ache, Runny Nose, and Normal Fever.

The project evaluates whether a controlled set of basic symptoms - such as Fever, Headache, Cough, Fatigue, and Body Pain - is sufficient to accurately predict and distinguish between overlapping diagnoses in a clinical context.

✨ WHAT WE DID

I worked on the project across the entire machine learning workflow, from initial data exploration and literature review to model tuning and evaluation.

  • 1. Technical Literature & Research
    We conducted research on state-of-the-art methods for multiclass classification in healthcare, analyzing papers focused on disease prediction, lung cancer classification, and gestational weight gain. Based on this, we decided to compare a baseline Random Forest model with XGBoost.
  • 2. Exploratory Data Analysis (EDA)
    We analyzed a dataset of 5,000 records to check distributions and class balances. We scaled features (transforming Fever to match the 0-10 scale of other symptoms), uncovered clinical correlations through boxplots, and evaluated multicollinearity using correlation matrices.
  • 3. Data Preprocessing & Power Analysis
    We handled the right-skewed distribution of the symptom data by applying a log transformation log1p(x). We performed a power analysis confirming that our balanced dataset (625 samples per disease) heavily exceeded the standard guidelines for statistical reliability.
  • 4. Requirements Analysis & Model Selection
    Based on a comprehensive comparison matrix evaluating Logistic Regression, SVM, and Random Forest against our data characteristics, we decided to select Random Forest for its robustness against multicollinearity and ability to capture non-linear, overlapping symptom patterns without strict normality assumptions. We went with XGBoost as our second model, as we were obliged to select one model that was not introduced throughout the lectures. This model was widely used in current state of the art, as we found out during technical literature review.
  • 5. Model Training & Hyperparameter Tuning
    We implemented stratified sampling for an 80/20 train/test split. We conducted a comprehensive grid search to optimize the Random Forest parameters (mtry, ntree, nodesize, maxnodes) using the Macro F1 Score as the primary metric to ensure balanced class performance.
  • 6. Threshold Optimization & Evaluation
    We evaluated both Random Forest and XGBoost using confusion matrices and multiclass ROC/AUC curves. To address misclassifications caused by overlapping respiratory symptoms, we implemented class-specific probability threshold tuning to optimize the balance between sensitivity and precision.

✨ WHAT DID I LEARN?

This project gave me hands-on experience with the complete predictive modeling pipeline, highlighting that machine learning is as much about data understanding as it is about algorithms. I learned how to deal with non-linear class boundaries and how to critically evaluate models beyond simple accuracy.

The most valuable takeaway was understanding the real-world trade-offs in model evaluation. While the untuned Random Forest achieved the highest overall accuracy (93%), optimizing decision thresholds proved essential for shifting the balance between false positives and false negatives—a critical requirement in medical diagnostics where missing a condition can have severe consequences.
