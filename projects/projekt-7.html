🐾 Class imbalance in animal image classification

🧬 Deep learning 📅 April 2025 🏫 School Project

✨ ABOUT PROJECT

This project was developed as part of the Neural Networks course during my studies at FIIT STU. I worked on it as a team with my classmates Lenka & Martin ♡.

The goal of the project was to explore the class imbalance problem in the context of image classification. We trained CNN models to classify animal images across 10 categories and systematically compared how different strategies for handling imbalanced data — oversampling, undersampling, and training on the original imbalanced dataset — affect model performance.

The dataset contained approximately 28,000 animal images belonging to 10 classes: dog, cat, horse, spider, butterfly, chicken, sheep, cow, squirrel, and elephant — with significant class imbalance present from the start (ranging from ~1,000 to over 3,300 images per class).

✨ WHAT WE DID

I participated across the full deep learning pipeline — from exploratory data analysis and preprocessing to architecture design, training, and final evaluation across multiple experimental setups.

  • 1. Technical Literature & Research
    We reviewed a paper focused on the class imbalance problem in deep learning, which guided our experimental design. Based on this, we set up a framework to compare the impact of oversampling, undersampling, and using the original imbalanced distribution on classification performance.
  • 2. Dataset & EDA
    We analyzed the dataset structure by plotting the distribution of images across classes, visually inspecting sample images to assess quality and labeling accuracy — during which we identified several mislabeled images. We also examined image resolution variance, which was found to be high across the dataset.
  • 3. Data Preprocessing
    We implemented a custom DataModule class handling data loading, augmentation, and balancing. All images were resized to 224×224 pixels. Training images underwent augmentation including random flips, rotations, affine transforms, and color jittering. Dataset was split 70/15/15 into train, validation, and test subsets using a fixed seed. To handle imbalance, we implemented a BalancerWrapper supporting optional online oversampling or undersampling modes.
  • 4. Model Architecture
    We implemented and compared three CNN architectures:
    • AlexNet — a classic deep CNN with batch normalization, dropout, and softmax output, used as our initial baseline. Implemented and customized mainly just for fun, as this architecture is originally for 2 channel images only.


    • SimpleNet — a custom CNN with a compact fully connected section, batch normalization, ReLU activations, max-pooling, and dropout.


    • SimpleNetV3 — a refined version of SimpleNet featuring smaller initial kernels, more channels at deeper layers, additional pooling, global average pooling, LeakyReLU activations, and dropout between convolutional layers to address overfitting.


  • 5. Experiments
    All final experiments used SimpleNetV3 trained for 60 epochs with the AdamW optimizer, CosineAnnealingLR scheduler, and CrossEntropyLoss with label smoothing (0.1). We compared three dataset strategies:
    • Undersampled (1,000 samples per class) — test accuracy ~66%, F1 ~65%
    • Oversampled (3,397 samples per class) — test accuracy ~81%, F1 ~80%
    • Original imbalanced — test accuracy ~76%, F1 ~74%
    Oversampling consistently produced the strongest results across all metrics.
  • 6. Evaluation
    Models were evaluated using accuracy, precision, recall, F1-score, top-1 and top-5 accuracy, and confusion matrices. All runs were tracked in Weights & Biases. Our best model — SimpleNetV3 trained on the oversampled dataset — achieved ~81% test accuracy and a top-5 accuracy of 98%.

✨ WHAT DID I LEARN?

This project gave me a deep appreciation for how much data quality and distribution matter in deep learning — sometimes more than the model architecture itself. I learned how to design and implement a full image classification pipeline from scratch, including custom data loading, augmentation strategies, and architecture iteration.

The most important takeaway was understanding the real-world trade-offs between oversampling and undersampling. While oversampling delivered the best results, it also came with significantly higher training time and a greater risk of overfitting on synthetic data. Undersampling was faster but lost valuable information.
