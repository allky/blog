🏠 House Price Prediction with MLP

🧬 Deep learning 📅 March 2025 🏫 School Project

✨ ABOUT PROJECT

This project was developed as part of the Neural Networks course during my studies at FIIT STU. I worked on it as a team with my classmates Lenka & Martin ♡.

The goal of the project was to solve a regression problem — predicting California house prices using a Multi-Layer Perceptron (MLP) trained with the Adam optimizer. The dataset contained ~20,000 records with 9 features including median income, housing age, location coordinates, and household statistics.

A key part of the project was an extensive hyperparameter study — experimenting with different activation functions, dropout rates, batch sizes, learning rates, and hidden layer configurations — as well as a comparison of Adam against other state-of-the-art optimizers (RMSProp, SGD, AdaGrad, NAdamW), validated against findings from the original Adam paper ↗.

✨ WHAT WE DID

I participated across the full pipeline — from data exploration and preprocessing to model training, hyperparameter sweeps, and final evaluation.

  • 1. Dataset & EDA
    We worked with the California Housing dataset (~20,640 samples, 9 features). We checked for null values, analyzed feature distributions, and identified the need for outlier removal and data transformation. After preprocessing, the dataset was reduced to 17,621 samples. We also generated a correlation heatmap to assess which features were most predictive of the target variable.
  • 2. Preprocessing
    We removed outliers, applied feature scaling and transformation, and also scaled the target variable to improve model stability — meaning predictions had to be reverse-transformed back to the original scale. We evaluated multiple feature selection techniques, but since each gave different results, we kept all 9 features as predictors. The dataset was split 80/10/10 into training, validation, and test sets.
  • 3. Model Architecture & Training
    We built an MLP with configurable hidden layers, activation functions, batch normalization, and optional dropout. Our best-performing configuration used hidden layers [128, 64, 32], ReLU activation, batch size 1000, learning rate 0.001, and the Adam optimizer. We used MSE as the loss function and evaluated with MSE, MAE, and RMSE. Early stopping was implemented to prevent overfitting.


  • 4. Hyperparameter Experiments
    We ran systematic grid search sweeps via Weights & Biases across 8 sweep configuration files, each isolating a different hyperparameter:
    • Dropout rate — no significant difference across values; best at ~23%
    • Hidden layers — [128, 64, 32] outperformed shallower architectures
    • Batch size — batch size 100 achieved the best generalization
    • Learning rate — 0.001 was optimal; 0.0001 converged too slowly
    • Activation functions — ReLU and LeakyReLU performed best; sigmoid performed worst due to vanishing gradients and limited output range
  • 5. Optimizer Comparison
    We compared Adam, RMSProp, SGD, AdaGrad, and NAdamW in two setups — with and without dropout. Adam consistently performed best without dropout. With dropout at 50% and a lower learning rate, RMSProp slightly outperformed Adam, while AdaGrad was the weakest optimizer in the dropout setting — consistent with the findings of the original Adam paper.

✨ WHAT DID I LEARN?

This project introduced me to the full regression modeling workflow with neural networks — from raw data exploration to systematic hyperparameter tuning and optimizer benchmarking. I learned how to structure experiments properly using sweep configurations and how to interpret results across multiple metrics rather than relying on a single number.

The most valuable insight was understanding how sensitive MLP performance is to seemingly small decisions — like the choice of activation function or learning rate. Seeing Adam's robustness confirmed across our own experiments, and matching the conclusions of the original paper, was a satisfying moment that made the theoretical knowledge feel much more concrete.
